# KOJ Alstonville & Wollongbar — Founding members

Landing page for the founding members list of Kingdom of Jiu Jitsu Alstonville & Wollongbar.

- `index.html` — the page (static, no build step)
- `img/` — photos and the official KOJ lion
- Sign-ups: paste the Google Apps Script `/exec` URL into `SCRIPT_URL` in `index.html`
